# 03 — API Contract (REVISED v1.1)

Base URL (dev): `http://localhost:8000`
Docs: `GET /docs` (Swagger UI, auto-generated by FastAPI)

## Changes from v1.0
- Added `html_features_available` boolean to POST /predict response
- Risk level thresholds aligned: low (0-33), medium (34-66), high (67-100)

---

## POST /predict

Extract features from a URL, classify it, and persist the result.

**Request body**
```json
{
  "url": "https://secure-login.example-bank.verify-account.com"
}
```

**Request schema**
| Field | Type | Rules |
|---|---|---|
| `url` | `HttpUrl` (Pydantic) | required, must be a valid absolute URL |

**Response `200 OK`**
```json
{
  "scan_id": 145,
  "url": "https://secure-login.example-bank.verify-account.com",
  "domain": "example-bank.verify-account.com",
  "prediction": "phishing",
  "confidence": 0.94,
  "risk_score": 94,
  "risk_level": "high",
  "html_features_available": false,
  "model_version": "xgb_v1_2026-07-22",
  "features": {
    "url_length": 58,
    "num_dots": 4,
    "num_subdomains": 3,
    "has_https": true,
    "has_ip_address": false,
    "...": "... remaining of 22 features"
  },
  "top_features": [
    {"name": "num_subdomains", "value": 3, "impact_score": 0.21, "direction": "increases_risk"},
    {"name": "url_entropy", "value": 4.1, "impact_score": 0.17, "direction": "increases_risk"},
    {"name": "has_https", "value": true, "impact_score": 0.05, "direction": "decreases_risk"}
  ],
  "scanned_at": "2026-07-22T12:30:00Z"
}
```

**New field: `html_features_available`**
| Value | Meaning | Frontend Behavior |
|---|---|---|
| `true` | Page was successfully fetched and HTML features were computed | Show full analysis |
| `false` | Page fetch failed/timeout; HTML features defaulted to 0/False | Show note: "Analysis based on URL structure only. Page could not be reached." |

**Errors**
| Status | Condition |
|---|---|
| `422 Unprocessable Entity` | Malformed URL / missing `url` field (Pydantic validation) |
| `500 Internal Server Error` | Model not loaded, or unexpected extraction failure |
| `503 Service Unavailable` | Model artifact missing on disk at startup |

## GET /history

Paginated scan history with optional filtering.

**Query params**
| Param | Type | Default | Notes |
|---|---|---|---|
| `page` | int | 1 | 1-indexed |
| `per_page` | int | 10 | max 100 |
| `prediction` | string | none | `phishing` \| `legitimate` |

**Response `200 OK`**
```json
{
  "items": [
    {
      "scan_id": 145,
      "url": "https://example.com",
      "prediction": "legitimate",
      "confidence": 0.88,
      "risk_level": "low",
      "scanned_at": "2026-07-22T12:30:00Z"
    }
  ],
  "pagination": {
    "page": 1,
    "per_page": 10,
    "total_items": 237,
    "total_pages": 24
  }
}
```

---

## DELETE /history/{id}

**Path param**: `id` (int, `ScanHistory.id`)

**Response `204 No Content`** on success.
**Response `404 Not Found`** if the id doesn't exist.

## Cross-Cutting Conventions

- All error responses follow: `{"detail": "human-readable message"}` (FastAPI default), with structured logging server-side for the same event.
- Timestamps: ISO-8601 UTC.
- CORS: allow-list `http://localhost:5173` in dev; environment-driven origin list in prod.
- No authentication in this version (mini-project scope) — noted as a Future Work item in `PROJECT_REPORT.md`.
- **Risk level thresholds:** `low = 0-33`, `medium = 34-66`, `high = 67-100`.
