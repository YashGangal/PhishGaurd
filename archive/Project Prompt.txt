BACKEND REQUIREMENTS:

1. FEATURE EXTRACTION (services/feature_engineering.py)
   - Implement ALL 22 features from the Feature Engineering Spec
   - Each feature must be a pure function with type hints
   - Handle malformed URLs gracefully (return safe defaults)
   - Include unit tests for each feature extractor

2. MODEL TRAINING (ml/train.py)
   - Load dataset from ml/data/
   - Preprocess: remove duplicates, handle missing values, SMOTE balancing
   - Train 4 models: LogisticRegression, RandomForest, XGBoost, SVM
   - Evaluate with: Accuracy, Precision, Recall, F1, ROC-AUC
   - Save best model as models/best_model.pkl
   - Save comparison results as ml/comparison_report.json

3. FASTAPI APP (app/main.py + routers/)
   - CORS enabled for localhost:5173 (Vite dev server)
   - Auto-generated Swagger UI at /docs
   - Pydantic validation on ALL inputs
   - Structured JSON logging
   - Global exception handlers (return proper HTTP status codes)
   - SQLite database with async or sync SQLAlchemy

4. PREDICTION ENDPOINT (POST /predict)
   - Accept: {"url": "string"}
   - Validate URL format with Pydantic HttpUrl
   - Extract features → Load model → Predict → SHAP explain
   - Calculate risk_score (0-100) based on confidence
   - Determine risk_level: "low" | "medium" | "high"
   - Save result to SQLite ScanHistory table
   - Return full response with features, top_features, scan_id

5. HISTORY ENDPOINTS
   - GET /history?page=1&per_page=10&prediction=phishing
   - DELETE /history/{id}
   - Include pagination metadata in response

6. EXPLAINABILITY
   - Use SHAP TreeExplainer (for tree models) or KernelExplainer
   - Return top 5 features with: name, value, impact_score, direction
   - Direction = "increases_risk" or "decreases_risk"
